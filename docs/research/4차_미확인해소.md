### 2-4. 부록 「AI 기술별 아이템 및 평가 기준(예시)」 (p.9 원문) — 그대로 자기 점검표

| AI 기술 | 평가기준 예시 | 감점요인 예시 |
|---|---|---|

| 데이터 분석·예측 AI | 예측 모델 타당성(회귀·시계열) / 정확도·성능 개선 효과 / 실제 의사결정에 활용 가능한 수준 / 개인화 | **단순 통계 수준(AI 아닌 경우)** / 결과 해석 불가능 |

| 언어·텍스트 AI | 자연어 이해 정확도 / 문맥·응답 품질 / 도메인 특화 학습 / **환각 최소화** | **단순 GPT 붙이기 수준** / 잘못된 정보 생성 |
| 이미지·영상 AI | 객체 인식 정확도 / 실제 환경 적용(조명·각도) / 데이터셋 품질 / 실시간 처리 | 엣지 케이스 대응 부족 / 데이터 부족 |
| 생성형 AI | 생성 품질 / 목적 적합성 / 프롬프트·파인튜닝 설계 / 저작권·윤리 | 단순 API 호출 / 결과 품질 불안정 |

유의사항 원문: "AI 기술의 필연성: 단순히 AI기술을 적용했다는 사실보다, **'왜 이 문제를 해결하는 데 이 AI 기술과 이 공공데이터가 꼭 필요한가?'에 대한 논리적 연결성**이 중요합니다." / "핵심이 되는 주 AI기술을 선택하되 복합 활용은 상세 기술".

사각119 방식(에이전트+RAG+지도)을 이 표에 대면: 에이전트는 "MCP/API 연동·end-to-end·오류 대응"을 화면에서 보여줘야 하고, 예측 모듈은 "단순 통계"를 넘는 모델 근거(검증 수치)가 있어야 하며, 챗 UI만 있으면 "단순 GPT 붙이기"로 깎인다. 계획서 3장(기술)에 **주 AI기술 1개 지정 + 이 표의 평가기준 열을 항목별로 답하는 구조**로 쓰면 범정부 경험 심사위원 눈에 맞는다.

### 2-5. 참가 제외·입상 취소 (p.6 원문, 안양 공고의 원본)

- 동일 아이디어로 복수 기관예선 동시 출품·복수 수상 시 1개 예선 선택

- **유사성·동일성 판단은 심사위원 과반수 동의**

## 6. 행안부 「AI 정부 서비스 사례집」 — 지자체 2건

### 6-1. 서울 강남구 「AI 부정주차 관리시스템」(주차관리과)
- 거주자우선주차구역 + 공유주차. 차량번호 인식 → 현장 즉시 판별·음성 안내 → 재안내→경고→행정 연계 단계 대응 → 앱 요금 정산·행정망 연계. 관·민 공동 특허.
- 세 원칙: 배정자·예약자 불편 없음 / 사후 단속 대신 현장 계도 / 도시 미관.
- 의미: **주차는 이미 행안부 대표 AI 사례가 있는 영역**. 안양 2024 최우수(주정차 EDA)·성남 2024·vworld 2025 대상(불법주정차-소방)까지 겹치면 "주차" 주제는 독창성 15점에서 시작부터 불리.

### 6-2. 경기도 「경기데이터 찾아드림」(AI데이터행정과)
- 경기데이터드림 포털 안의 생성형 AI 검색. 모델 **OpenAI GPT-4.1**, RAG 기반 자연어 질의응답·요약·추천·분석 도우미. 서비스 개시 2024.8. 예산 **'24~'26 1.2억(2천·5천·5천만)**. 2026년 통합데이터플랫폼 + 경기도 자체 LLM 전환 계획.
- 주요 이슈(원문): 데이터 품질 관리 미흡(기관별 형식 불일치), 서비스 안정화, 단순 검색·요약만으로는 체감 한계.
- **전문가 제언(포티투마루 정휘웅)**: "통계 데이터는 확률적 '생성'이 아닌 확정적 '계산'의 영역 → 통계 산출 로직을 별도 계산 모듈로 두고 AI는 이 모듈을 호출하는 **'에이전트 기반 아키텍처'** 추천… 전수 통합보다 다빈도·고수요 통계 유형별 특화 에이전트 서버". (서울대 고길곤) "LLM이 참조하는 메타데이터 품질·구조화가 뒷받침돼야".
- 의미: 안양 출품작의 AI 구조를 "LLM은 인터페이스, 수치는 검증된 계산 모듈, 근거는 RAG"로 쓰면 행안부 사례집의 전문가 제언과 같은 문장이 된다. 안양이 쓰는 경기데이터드림 API의 상위 기관이 이미 이 구조를 표준으로 잡았다는 뜻.

나머지 12사례(홍수예보 LSTM, 스마트정수장, 산재조사 분류, 근로감독관 AI, 복지위기가구 초기상담, 경기도 360˚ AI+돌봄, 운전자격 게이트, 딥페이크 탐지, 경사연 연구지원, 광주 AI 당직, 용산구 다국어 민원, 인천공항 여객흐름, 특허심사, 법제처 법령 AI)는 안양 후보와 직접 겹치는 것 없음. 단 "24시간 AI 민원상담" 쪽으로 가면 용산구·법제처 사례가 비교 대상이 됨.
