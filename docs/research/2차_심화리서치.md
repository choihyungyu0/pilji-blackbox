## 0. 2차에서 바뀐 결론 (1차 대비 수정·강화)

1. **사각119 중복 리스크는 '공식 목록' 기준으로는 없다.** 소방청 「제6회 소방안전 빅데이터 경진대회」는 범정부 예선기관(2024·2025·2026 목록)에 **등록돼 있지 않다** → 공공데이터포털 349번 「최근 3년 예선기관 수상내역」에 사각119가 들어갈 수 없다. 남는 리스크는 (a) 서약서 2항 "출품작이 타 기관 경진대회에 입상·수상 실적 없음" — 새 작품이면 무관, (b) 공개검증 10일간 제3자 제보 — 소통24 후보작 페이지에 **활용 공공데이터 목록·예선기관까지 공개**되므로 누구나 sagak119와 대조 가능. 결론: 문제·데이터·기능이 다르면 안전, 구조만 복사하면 제보 대상.
2. **AI전략국은 '예산 없는 신설국'이다.** 의회 회의록 원문: AI전략사업단 2026 본예산 **730만원**("총무경제위원회 1년 예산보다 적은"), 업무보고가 전부 "예산확보"로 표기. 1회 추경(4/13)에서야 **24시간 AI 민원상담서비스 8억4천만원 + AI분석기반시스템 고도화 1억5천만원**이 잡혔다. → 출품작이 "우리 시가 이미 잡은 8.4억·1.5억 사업에 들어가는 모듈"이면 발전가능성 항목에서 즉시 통한다. 새 예산을 요구하는 제안은 의회 지적을 그대로 맞는다.
3. **2026 범정부 대회와 미연계 확정.** ~~2026 예선기관 목록(40건)에 안양시 없음~~ → **정정(9/16, 4차 문서 §2)**: 행안부 제14회 통합공고(4.8) 기초 예선기관 5곳에 안양시 "대학생 공공데이터 활용 경진대회(6.1~7.31, 제품·서비스 개발)"로 등록돼 있었음. 7.13 수정 통합공고(제2026-898호)에서 안양시 삭제(44개 기관) → 8.6 독립 대회로 결재(AI정책과-6623). 티켓 없음은 동일. 2027 추천 여부는 공고에 없음.
4. **의회가 반복 지적하는 3가지 = 심사위원(실무진)이 방어하고 싶은 3가지**: ① 예산·조직 실체 부재 ② "AI가 행정력을 대체한다는 착시" ③ 개발 후 유지관리·부서 연계 부재(정보통신과 의존). 사업계획서에 (담당팀·붙는 예산라인·운영주체·데이터 갱신 경로)를 한 표로 넣으면 이 셋을 한 번에 막는다.
5. **3D 건물의 현실적 소스는 브이월드 2D데이터 API `LT_C_SPBD`**(도로명주소 건물 외곽선 + 지상층수 `gro_flo_co`, bbox·`sig_cd` 필터, 페이지당 1,000건, 키 즉시). 브이월드 3D API 3.0은 Cesium 3D Tiles를 쓰지만 tileset 엔드포인트가 비공개·키 바인딩이라 자체 뷰어에 직접 로드는 미확인. 6일 권장 스택은 아래 §6.

### 6-2. 브이월드 3D 지도 API 3.0 사실관계
- Cesium 기반 확인: 스크립트 `https://map.vworld.kr/js/webglMapInit.js.do?version=3.0&apiKey=KEY`, 전역 `ws3d.viewer`(Cesium.Viewer), 건물 피킹 결과 `Cesium.Cesium3DTileFeature` → **건물이 3D Tiles로 스트리밍**. 옵션 terrain/buildings/roads/water/vegetation. 샘플: https://raw.githubusercontent.com/V-world/V-world_API_sample/master/[WebGL3]%20클릭된%20모델%20숨기기.html
- tileset.json URL은 공개 문서에 없고 키·도메인 바인딩 `(추정)` → 자체 CesiumJS/MapLibre에 직접 로드는 미확인·약관 리스크. **임베드 뷰어(광역 실감 화면 1장)로만 병행.**
- 3D 건물 원천 SHP(GIS건물통합정보, 높이·층수·사용승인 통합, 전국 665만 동)는 브이월드 오픈마켓 `https://www.vworld.kr/dtmk/dtmk_ntads_s002.do?svcCde=NA&dsId=18` — 로그인 다운로드 → §8.
- 국토지리정보원 3D 건물(LOD)·CityGML은 data.go.kr 메타에 없고 map.ngii.go.kr가 비브라우저 차단 → §8에서 사용자 확인 요청.

### 6-3. 6일 권장 스택 (1개)
**MapLibre GL JS(+deck.gl 선택) + 브이월드 WMTS Satellite 배경 + `LT_C_SPBD` 건물 GeoJSON fill-extrusion(층수×3.3m, 색=경과연수/점수) + Terrarium 지형 + Sentinel-2 COG·Landsat ST·GHSL·WorldCover 래스터(titiler 또는 사전 타일링) + 건축HUB 조인 카드(클릭 시) + HWPX 결재문서 + 출처각주 에이전트.**
근거: 3D 건물의 유일한 즉시·무승인 벡터 소스가 `LT_C_SPBD`; 서버에서 한 번 긁어 정적화하면 키 한도·CORS·`domain` 바인딩에서 자유; SHP 다운로드가 되면 높이·사용승인일·용도를 조인해 정확도 상향. 브이월드 3D API는 뷰어 종속, Cesium ion은 비상업·15GB/월·OSM 커버리지 문제. 위성은 AWS COG로 이틀 내 열섬·NDVI 레이어 가능.
