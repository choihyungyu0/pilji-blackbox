2026 안양시 공공데이터·AI 활용 대학생 경진대회 출품 시제품. **접수 마감 2026-09-21(월)**, 시제품 완성 상태 필수.

## 한 줄

안양 건물 27,713동의 공개 데이터를 AI로 분석해 **위반건축물 우선조사 후보**를 찾고, 필지별 **사고·위반·공사 이력 타임라인**을 한 화면에 보여주고, 담당 공무원이 결재할 **현장조사 기안문·사전통지서 초안(HWPX)** 까지 만드는 웹 서비스.
