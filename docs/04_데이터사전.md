## 3. changes_20250904_20260909.json

2025-09-04와 2026-09-09 건물통합정보 전체본을 `id`로 조인해 A20 비교.

```json
{"snapshots":["2025-09-04","2026-09-09"],
 "counts":{"viol_added":88,"viol_cleared":64,"new_building":1},
 "changes":[{"id":16818,"type":"viol_added","pnu":"...","dong":"안양동","jibun":"707-115","use":"단독주택","lon":..,"lat":..,"from_date":"2025-09-04","to_date":"2026-09-09","source":"..."}]}
```

type: `viol_added`(N→Y), `viol_cleared`(Y→N), `new_building`(2025 스냅숏에 없음). 타임라인 이벤트 날짜는 "2025-09-04~2026-09-09 사이"로 표기(정확한 일자 아님).
