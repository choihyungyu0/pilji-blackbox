## 제출 전 검수 체크리스트

### 데이터 정합성
- [ ] 건물 27,713동 표시, 위반 표기 1,573, 대장 미연계 4,112, 후보 1,918(A 913 / B 1,005)
- [ ] 1년 변화: 신규 위반 88, 해제 64
- [ ] 모델 카드: 공간 AUC 0.728, 시간 AUC 0.698, 상위 20% 포착 46.8% / 46.6%
- [ ] 급경사지 47곳 표시(위치화 실패 건수 표시), 시 발표 59곳 문구
- [ ] 모든 레이어·카드에 출처·기준일
- [ ] 출처 페이지에 안양시 데이터 6종 + 건물통합정보 + 급경사지 + 브이월드 API URL

### 원칙
- [ ] 공개 모드에서 필지 단위 후보가 보이지 않음(격자 집계만)
- [ ] 판정≠위반이면 사전통지 버튼 비활성
- [ ] 문서 초안에 "초안 — 담당자 검토 필요" 머리말
- [ ] 어떤 화면에도 소유자·거주자 개인정보 없음
- [ ] 결측이 0이 아니라 "정보없음"으로 표시
- [ ] 에이전트가 도구 실패를 답변에 명시
- [ ] 박달동 사고 원인 단정 문구 없음

### 동작 (완성도 20점)
- [ ] 첫 화면 3초 내 표시(데스크톱), 모바일에서 깨지지 않음
- [ ] 브이월드 키 없을 때 OSM 폴백 + 배너, 앱이 멈추지 않음
- [ ] OpenAI 키 없을 때 에이전트 화면에 "키 필요" 안내, 다른 화면 정상
- [ ] 판정 저장 실패 시 임시 보관·재시도
- [ ] HWPX가 한글에서 열림(표 깨짐 없음)
- [ ] 콘솔 에러 0
- [ ] 배포 URL이 로그인 없이 공개 모드로 열림

### 사업계획서 연결
- [ ] 계획서 3장 데이터 표 = 출처 페이지 목록과 동일
- [ ] 계획서의 모든 수치 = 화면 수치
- [ ] 화면 캡처: 지도, 필지 패널, 조사 목록, 에이전트·문서, 성과
